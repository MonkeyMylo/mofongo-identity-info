Mofongo Home

Google sign-in for a small set of private apps that one family runs on its own home network.

The apps are household tools, such as a shared photo library and a personal budget ledger. They are reachable only from the family's home network and private VPN, and only people the family has invited can use them.

Google permissions

Mofongo Home asks Google only for basic sign-in information: your name, email address and profile picture (the openid, email and profile scopes). It uses them to confirm who is signing in. It requests no access to Gmail, Drive, Calendar or any other Google data.

Personal use

This is a private family utility, not a hosted service. It has no public sign-up. This website contains information about the application only. It does not provide access to any app, account data or authorization credentials.
